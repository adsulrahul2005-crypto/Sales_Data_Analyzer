# Sales Data Analyzer 📊

## 📌 Project Overview

**Sales Data Analyzer** is a data analysis web application developed using **Python, Pandas, and Streamlit**.

The project helps users analyze sales data and understand important business information such as total sales, quantity sold, product categories, cities, and sales trends.

## 🛠️ Technologies Used

* Python
* Pandas
* Streamlit
* CSV
* Data Analysis

## ✨ Features

* 📂 Load sales data from CSV file
* 📊 Analyze sales data
* 💰 Calculate total sales
* 📦 Analyze quantity sold
* 🏷️ Filter data by category
* 🏙️ Filter data by city
* 📅 Analyze sales based on date
* 📈 Display data in an interactive Streamlit dashboard

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/adsulrahul2005-crypto/Sales_Data_Analyzer.git
```

### 2. Open the Project Folder

```bash
cd Sales_Data_Analyzer
```

### 3. Install Required Libraries

```bash
pip install pandas streamlit
```

### 4. Run the Streamlit Application

```bash
streamlit run app.py
```

The application will open in your browser.
